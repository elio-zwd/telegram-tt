# Telegram Web K 自定义图片停留时间

## 1. 结论

P1-04 在保留 `2、3、5、8、10、15、30 秒`预设的基础上，增加全局自定义图片停留时间。

```text
Base：codex/tampermonkey-media-continuity@cfa586dfdb7fbf63c633b9b1480bde7fd007ec1f
开发分支：feat/tampermonkey-web-k-custom-photo-duration
目标版本：0.4.0-k9
```

本功能只作用于 Telegram Web K，不修改 Web A、Telegram 桌面源码、平台导航、关闭定位或快捷键模块。

## 2. 输入和精度

有效范围：`1.0～300.0 秒`。

- 接受整数和一位小数；
- 保存前清理首尾空格；
- 使用普通十进制正则，不接受科学计数法、十六进制、符号或额外字符；
- 不进行浮点毫秒存储；
- 秒数按“整数秒 + 十分之一秒”转换为整数毫秒；
- 毫秒必须位于 `1000～300000`，并且能被 `100` 整除。

显示时整数省略 `.0`，例如 `12 秒`；一位小数保留，例如 `2.5 秒`。

## 3. 控制条交互

图片时间选择框保留全部预设，并增加“自定义…”。选择后显示紧凑输入区域：

```text
[秒数输入框] 秒 [应用]
```

- 输入框具有 `aria-label="自定义图片停留秒数"`；
- 点击“应用”或按 Enter 提交；
- 输入区域位于 Shadow DOM；
- 输入期间 Space、A、ArrowLeft 和 ArrowRight 不触发插件快捷操作；
- 窄窗口允许控件换行；
- 收起和重新展开后，已保存自定义值仍正确显示。

非法输入显示：

```text
请输入 1～300 秒，最多一位小数
```

非法提交不调用设置保存，不重启 timer，不改变连续浏览、暂停、方向、筛选或关闭定位状态。

## 4. 持久化兼容

继续只使用：

```text
tt.mediaContinuity.v1
```

设置字段保持：

```text
continuousEnabled
photoDurationMs
browseDirection
mediaFilter
panelCollapsed
```

`photoDurationMs` 接受合法预设或合法自定义整数毫秒。旧扁平对象、`{ settings: ... }`、缺失字段、非法字段、损坏 JSON、读取异常和写入异常继续安全回退。保存时保留其他设置字段和已有顶层数据。

## 5. 会话行为

### 当前为图片

合法修改：

- 取消旧图片倒计时；
- 从完整新时长重新开始；
- 不按剩余时间折算；
- 不立即导航；
- 不改变连续浏览开关、暂停、方向、筛选和关闭定位目标。

暂停时仍保持暂停，恢复后从完整新时长开始。连续浏览关闭时只保存，不自动开启。

### 当前为视频

只保存和刷新控制条，不调用图片调度，不重新播放视频，不触发导航。后续图片使用新时间。循环媒体策略继续留给 P1-05。

### 当前处于筛选跳过

不接管或恢复筛选序列，不建立第二套导航 timer。中间媒体继续保持目标确认屏蔽；真正匹配的图片稳定显示后，才按新时间调度。

## 6. 失败场景设计

实现和验收覆盖：

1. 旧值 `5000`；
2. 预设 `8000`；
3. 自定义 `2.5`、`1`、`300`、带空格的 `2.5`；
4. 拒绝 `0.9`、`300.1`、`1.23`、`abc`、空字符串、科学计数法、负数、只有小数点和十六进制；
5. storage 中合法自定义值 `2500` 正确恢复；
6. storage 中非法值回退默认；
7. 损坏 JSON、localStorage 读取或写入失败不抛出未捕获异常；
8. 图片计时中修改重启完整时间；
9. 暂停中、关闭状态和视频中修改保持原状态；
10. 快速连续提交以最后一次合法值为准；
11. Enter、收起展开、刷新和重新打开查看器；
12. 正向、反向与三种媒体筛选组合；
13. 筛选跳过中不启动错误倒计时；
14. Space、A 和文本方向键互不冲突；
15. 关闭定位不回归。

## 7. 静态门禁

`check:tampermonkey:web-k` 核对：

- 版本、唯一 Web K `@match` 和 `@grant none`；
- 唯一 storage key；
- 1 秒下限、300 秒上限和 100ms 精度；
- 普通十进制、一位小数解析；
- 合法自定义毫秒可通过设置校验；
- 旧预设继续存在；
- 输入框可访问性、应用按钮和 Enter；
- 非法值在 UI 和会话两层被拒绝；
- 视频修改不触发图片调度；
- 媒体筛选和快捷键原门禁继续保留；
- 单文件 IIFE、无动态 import、额外 chunk 或 sourcemap；
- legacy 继续删除，Web A 未修改。

## 8. 构建和浏览器验证边界

GitHub Actions 必须在 Linux 和 Windows 连续构建两次、比较 SHA-256、执行静态门禁、语法检查、生成文件一致性和差异检查。

构建和 CI 不替代真实 Telegram Web K 浏览器验收。真实浏览器必须覆盖设置、图片、视频、筛选、快捷键、关闭定位和 Telegram 原页面回归；完成前 PR 保持 Draft。

## 9. 回滚

可整体回滚本 PR。旧版本会把非预设自定义值回退为默认 5 秒，但不会破坏同一 storage key 的其他字段。用户侧也可停用 Tampermonkey 脚本恢复 Telegram 原行为。
